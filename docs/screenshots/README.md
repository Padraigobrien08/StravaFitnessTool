# Screenshots

The main [README](../../README.md) references `home.png` here (and optionally
`intelligence.png`, `goals.png`). To generate them:

1. `npm run dev` → open http://localhost:3000
2. Click **Try the demo** (loads the sample athlete).
3. Screenshot these routes and save them here with these exact names:
   - `/home` → `home.png`
   - `/intelligence` → `intelligence.png`
   - `/goals` → `goals.png`

Tip: a ~1440px-wide window in dark mode gives the cleanest capture. Commit the
PNGs and the README images render automatically.
